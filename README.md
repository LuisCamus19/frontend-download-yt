# 💻 YouTube Converter - Frontend

Interfaz web que permite al usuario ingresar enlaces de YouTube y seleccionar el formato de descarga.

## 🛠️ Tecnologías
* **Framework:** [Angular]
* **Estilos:** [CSS]
* **Conexión:** Consume la API del Backend.

## ⚙️ Configuración y Ejecución

**Prerrequisitos:** Tener instalado Node.js.

1.  **Instalar dependencias:**
    ```bash
    npm install
    ```
2.  **Iniciar el entorno de desarrollo:**
    ```bash
    # Si es Angular
    ng serve
    
    # Si es React/Vite
    npm run dev
    ```
3.  **Ver en el navegador:**
    Abre `http://localhost:4200` para ver la aplicación.
